# Г.Т. Строй постове

Мобилно приложение (PWA) за Facebook страницата на Г.Т. Строй 2025 ЕООД:
качвате една заглавна снимка от обекта, попълвате данните и приложението прави
готово заглавно изображение + текст за публикацията.

- Шаблони: **Обектът** (площ, етажи, срок), **Етап / прогрес** (%), **Гриши казва**
- Формати: пост 4:5, квадрат, сторис/рийл 9:16
- „Сподели във Facebook“ копира текста и изпраща снимката към Facebook

## Пускане
1. Качете папката в GitHub → Settings → Pages → Branch: `main` / root.
2. Отворете адреса в Chrome на телефона → меню ⋮ → **Инсталиране на приложението**.
3. За APK файл / Google Play: въведете адреса на pwabuilder.com → Android.
