# Г.Т. Строй постове

Мобилно приложение (PWA) за Facebook страницата на Г.Т. Строй 2025 ЕООД:
качвате снимки от обекта, попълвате данните (или оставяте приложението да ги извади
от описанието на Гриши) и получавате готова картинка + текст за публикацията.

## Какво може
- **Снимки:** до 4 (колаж). Всяка се мести, увеличава и подрежда; големите телефонни снимки
  се смаляват автоматично.
- **Шаблони:** **Реклама** (колаж + данни + описание от Гриши), **Преди / След**,
  **Обектът** (площ, етажи, срок), **Етап / прогрес** (%), **Гриши казва**
- **Формати:** пост 4:5, квадрат, сторис/рийл 9:16 (в сториса долната лента е вдигната,
  за да не я закрива полето за отговор на Facebook)
- **„Попълни данните от описанието“** изважда площ, етажи, срок, стаи, място и тип от свободен текст
- **Моите обекти:** запазвате обект и после го зареждате (напр. всяка седмица само сменяте етапа).
  Всичко се запазва автоматично на телефона и след затваряне.
- **Текст за поста:** няколко варианта на края, ръчно редактиране без да се губи
- **Настройки:** телефон, фирма, надпис в долната лента, хаштагове
- „Сподели във Facebook“ копира текста и изпраща снимката към Facebook; „Запази снимката“ я сваля

Работи и без интернет (шрифтовете са в `fonts/`). Снимките не се запазват между сесиите,
само данните.

## Обновяване
`sw.js` е „първо мрежа“: при връзка с интернет приложението винаги взема последната версия
от GitHub Pages, без да се променя нищо. Версията на кеша (`CACHE`) се сменя само ако добавяте
нови файлове към `FILES`.

## Пускане
1. GitHub → Settings → Pages → Branch: `main` / root.
2. Отворете адреса в Chrome на телефона → меню ⋮ → **Инсталиране на приложението**.
3. За APK: `bubblewrap` (TWA) към адреса на Pages. За цял екран без лента с адрес е нужен
   `/.well-known/assetlinks.json` в корена на `<потребител>.github.io`.
